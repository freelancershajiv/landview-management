# LAND VIEW Website Analytics

Admin-only dashboard route: `/admin/website-analytics`.

The dashboard reads the existing first-party visitor analytics store through `/api/admin/website-analytics`. It shows all-time visitor/session/page-view totals, recent activity, top pages, referrers, devices, browsers, approximate IP geography, raw IP addresses for administrators, and consented precise-location events.

Precise browser location remains opt-in. IP-derived locations are approximate.
